# Homebrew Tap

Homebrew formulae maintained by Alexander D'Alesio.

## Focusrite Control API

Install the unofficial dual-transport Scarlett controller:

```bash
brew install alexanderdalesio/tap/focusrite-control-api
```

The application provides a CLI, local JSON API, and browser dashboard using direct USB/FCP or an authenticated Focusrite Control 2 connection.

Project documentation and compatibility details are maintained in the [main repository](https://github.com/alexanderdalesio/focusrite-control-2-api).
